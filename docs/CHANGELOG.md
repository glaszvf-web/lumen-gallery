## 华为 Mate 80 Pro Max 专项（用户真机反馈逐条闭环）
- RAW（DNG）：IFD0/SubIFD(CFA)/ExifIFD/GPS 四卡分组、黑电平/色彩矩阵/校准光源(扩展 D65)/前向矩阵/噪声模型全中文化——与参考软件逐项对齐
- LOG 视频：MediaExtractor 深挖 → 10bit/HLG/PQ/BT.2020 → "HDR/LOG 模式"判定；码率 Mbps
- 单位：像素改"xxxx 万像素"、码率 Mbps
- 找图痛点：从相册选图入口 + 格式 chips + 相册集 + 文件名搜索 + ‹›连续浏览

## 排雷记录（关键）
1. **ACCESS_MEDIA_LOCATION**：缺失时 FUSE 层现场抹零 GPS（shell 读却正常）——插桩对照定位
2. GIF 布局逐字节校对（头 6+LSD 7、GCT×3 字节、LZW 码长字节）
3. PIL 的 GPS 写入在 py3.12/3.14 全崩 → 手写 TIFF/EXIF 二进制 builder
4. TIFF SubIFDs 内联指针值读取 bug（e+8 是值不是地址）
5. Compose 按钮落入系统手势区 → 点击变回桌面（滚动至 y<2100 再点）
6. RawAccessFile 必须 readFully；JPEG SOF 偏移含 2 字节长度头
